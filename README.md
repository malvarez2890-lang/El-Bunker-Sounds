# El Búnker Sound

*Tu refugio musical.* App web instalable (PWA) para escuchar la música guardada en el servidor de casa y compartirla con amigos invitados.

- Instalación en el servidor: [`docs/SERVIDOR.md`](docs/SERVIDOR.md)
- Contexto para desarrolladores y sesiones de Claude: [`CLAUDE.md`](CLAUDE.md)
- Diseño original: [`design/`](design/)

Desarrollo local: `npm install && python3 scripts/make-test-music.py ./music 6 && MUSIC_DIR=./music npm run dev`, pruebas con `npm test`.
